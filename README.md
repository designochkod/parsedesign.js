# parsedesign.js
En enkel, snabb och liten Markdown parser i JS ES6+ på 5kb med stöd för externa länkar och CSS-klasser samt HTML kod i Markdown dokumentet.

## parsedesign.js
Version ett är fullt funktionell förutom fel vid rendering av sub-listor (ul/ol). Fungerar för övrigt som normalt.

## Version 1 av parserdesign.js
Fixar sub-lista problemet, men dess kodbas är större.
